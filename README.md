# HIKARI — 星灯りのリズム

Meta Quest Browser 向けの WebXR リズムゲームのプロトタイプです。星空で光を追い、右手のコントローラーに付いたライトブレードを振ってキャッチします。

## 3つのコース

- **月あかり** — 漂う光をゆっくり追う
- **星のリズム** — 左右から交互に来る光をリズムよく斬る
- **奥行きの道** — 手前と奥に交互に現れる光を斬る

ゲーム中は右手のライトブレードを振って光に通します。光は奥から現れ、外側の輪が縮んで金色に光る瞬間が斬りどきです。タイミングを逃しても光は残り、次の合図を待てます。Bボタンでコース選択に戻り、画面右上の「ホーム画面へ」で終了します。Quest BrowserではVR起動を、VR非対応ブラウザーでは画面プレイを案内します。デスクトップではマウスクリックで光をキャッチできます。A-Frame を CDN から読み込み、GitHub Pages のルートから配信します。

仮想の距離表現は、現実の目のピント調節を再現しません。このプロトタイプは視力回復や眼疾患の治療を目的としたものではありません。疲れ、頭痛、吐き気、複視などを感じたら中止してください。

## GitHub Pages

`main` ブランチのルートを GitHub Pages の公開元に設定します。
